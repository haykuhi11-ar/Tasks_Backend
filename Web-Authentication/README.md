# Basic Auth Task

## Overview
Simple Express server using HTTP Basic Authentication with hardcoded users.

## Features
- Public route (no auth)
- Protected routes (Basic Auth)
- Middleware for credential validation


# API Key Task

## Overview
Express API with API Key authentication and permission-based access control.

## Features
- API key authentication via `X-API-Key`
- Role/permission system (read/write)
- Public + protected routes


# JWT Auth Task

## Overview
Authentication system using JWT tokens.

## Features
- User register/login
- Password hashing (bcrypt)
- JWT token authentication
- Protected routes
